# Prairie Sky Weather Network

Twelve backyard weather stations, run by volunteers, reporting every
ten minutes. This repository holds the public station directory.

- `stations.csv`: every station, who runs it, and where it is.
- `CHANGES.md`: what's changed, newest first.

To make a change, work on a branch and open a pull request. Somebody
else reviews it before it's merged.

Every pull request should add a line to the top of `CHANGES.md`.
